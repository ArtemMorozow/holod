# Window Switcher

Нативный переключатель окон для macOS на Apple Silicon. Получает список окон через Accessibility API и позволяет выбрать отдельное окно приложения.

## Сборка

Нужны стабильный Rust с поддержкой edition 2024 и инструменты командной строки Xcode (`xcode-select --install`).

```sh
cargo build --release --locked
```

## Разрешение macOS

Откройте «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Для запуска из терминала разрешите доступ приложению терминала. Если macOS идентифицирует сам бинарник как источник запроса, добавьте `target/release/window-switcher`. Перезапустите процесс после выдачи разрешения. При отсутствии доступа CLI выводит инструкцию в stderr и возвращает код 1. [Инструкция Apple](https://support.apple.com/guide/mac-help/mh43185/mac)

## CLI

```sh
./target/release/window-switcher list
./target/release/window-switcher focus '<id из первого столбца>'
```

`list` выводит три столбца через табуляцию: ID, приложение и заголовок. Используйте свежий ID. Он может измениться при переименовании, перемещении или изменении размера окна либо при перезапуске приложения или пересборке бинарника. Если несколько окон одного приложения имеют одинаковые доступные метаданные, список показывает отдельные ID с порядковыми номерами, а `focus` сообщает о неоднозначности. Переместите одно из окон и обновите список.

В список попадают обычные окна и диалоги, которые пользовательские приложения публикуют в Accessibility. Системные окна, служебные панели и приложения, не ответившие в пределах тайм-аута, пропускаются. Для диагностики можно запустить CLI с `RUST_LOG=debug`.

## Панель поиска

```sh
./target/release/window-switcher gui
```

Запуск без аргументов тоже включает панель. Процесс работает без значка в Dock. Нажмите `Option+Tab`, чтобы открыть поиск. Если macOS отклонит регистрацию, приложение попробует `Control+Option+Space` и напечатает зарегистрированное сочетание в терминале. Чтобы выбрать другое сочетание, запустите `window-switcher gui --hotkey 'Ctrl+Alt+W'`.

Введите часть заголовка или названия приложения. Стрелки `↑` и `↓` меняют выбор, `Enter` переключает на окно, `Esc` скрывает панель. Успешное переключение закрывает панель. При отсутствии доступа панель показывает инструкцию по настройке. Для завершения процесса нажмите `Ctrl+C` в терминале, из которого его запустили.

## Spaces

При переключении macOS может перейти в Space, где уже открыто окно приложения. Включите параметр «При переключении на приложение переключаться на пространство с открытыми окнами этого приложения» в «Системные настройки → Рабочий стол и Dock → Mission Control». Через публичные API нельзя адресовать произвольный Space по ID. Если macOS не переводит фокус на выбранное окно, перейдите в нужный Space и повторите запрос. [Справка Apple о Spaces](https://support.apple.com/guide/mac-help/work-in-multiple-spaces-mh14112/mac)

## Ручная проверка

1. Откройте два окна VS Code с разными заголовками и убедитесь, что `list` показывает отдельный ID для каждого.
2. По очереди вызовите `focus` для обоих окон. Повторите со свёрнутым окном, окном другого приложения и окном на другом обычном Space.
3. Закройте окно и повторите `focus` со старым ID. Проверьте сообщение об ошибке и ненулевой код завершения.
4. Запустите `list` из процесса без доступа к Accessibility и проверьте подсказку о разрешении.
5. Запустите `gui`, откройте панель глобальным сочетанием и сразу введите часть заголовка. Убедитесь, что поиск регистронезависимый, стрелки меняют выделение, `Enter` переключает на выделенное окно, а `Esc` закрывает панель.
