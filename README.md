# Holod

Нативный переключатель окон для macOS на Apple Silicon. Получает список окон через Accessibility API и позволяет выбрать отдельное окно приложения.

## Установка на macOS

1. Откройте `holod-<версия>-macos-arm64.dmg` и перетащите **Holod** в **Программы (Applications)**.
2. Откройте Holod из «Программ». При первом запуске нажмите **Open System Settings**. В «Конфиденциальность и безопасность → Универсальный доступ» включите Holod. Если его нет в списке, нажмите «+» и выберите `/Applications/Holod.app`.
3. Снова откройте Holod. Нажмите сочетание вроде `⌃⌥K` или дважды быстро нажмите и отпустите одну клавишу, например `⌘ → ⌘`. Выберите **Save Shortcut**. Кнопка **Skip** оставляет двойное нажатие `Option`.
4. Если хотите, чтобы Holod открывался при входе в macOS, выберите **Start at Login**. Кнопка **Not Now** закрывает предложение. Позже автозапуск можно включить через **Start at Login** в меню снежинки.
5. В строке меню появится снежинка с буквой **H**. Откройте панель своим сочетанием или через **Search Windows**. Завершить приложение можно через **Quit Holod** в меню снежинки или `⌘Q` в панели поиска.

Для установленного приложения нужна macOS 26 или новее и Apple Silicon.

## Обновление

Выберите **Quit Holod** в меню снежинки, откройте новый DMG и перетащите Holod в **Программы**. В Finder выберите **Заменить**, затем откройте Holod из «Программ». Если macOS снова запрашивает разрешение после обновления локальной подписи, откройте «Универсальный доступ». При необходимости удалите старую запись Holod, добавьте `/Applications/Holod.app` и снова запустите приложение.

В релизах GitLab CI со Sparkle выберите **Check for Updates…** в меню снежинки. Holod также проверяет обновления в фоне. По умолчанию установка запускается после подтверждения. Первый релиз со Sparkle установите из DMG.

## Сборка

Нужны стабильный Rust с поддержкой edition 2024 и инструменты командной строки Xcode (`xcode-select --install`).

```sh
./packaging/macos/build.sh
```

Скрипт использует версию из `Cargo.toml` и создаёт `dist/Holod.app` и `dist/holod-<версия>-macos-arm64.dmg`. Приложение подписывается локальной подписью ad hoc. Для распространения скачиваемой сборки Apple предусматривает подпись Developer ID и нотарификацию. [Документация Apple об упаковке приложений](https://developer.apple.com/documentation/xcode/packaging-mac-software-for-distribution)

Чтобы собрать бинарник для запуска из терминала, выполните:

```sh
cargo build --release --locked
```

## Релизы в GitLab CI

Пайплайн на Apple Silicon прогоняет проверки Rust и сохраняет локально подписанный DMG в артефактах задания `build_macos`. По умолчанию используется раннер GitLab.com `saas-macos-medium-m1` с macOS 26 и Xcode 26. Для собственного раннера на Apple Silicon с Xcode 26 задайте его тег в переменной `MACOS_RUNNER_TAG`. [Раннеры GitLab на macOS](https://docs.gitlab.com/ci/runners/hosted_runners/macos/)

1. В проекте GitLab защитите теги `v*` и включите GitLab Pages с доступом без входа. Задание `publish_macos` использует `CI_PAGES_URL`. Для своего домена задайте `HOLOD_PAGES_URL` с базовым HTTPS-адресом сайта. Этот адрес встраивается в Holod, поэтому сохраняйте его между релизами. [Доступ к GitLab Pages](https://docs.gitlab.com/user/project/pages/pages_access_control/)
2. Подготовьте сертификат **Developer ID Application** с закрытым ключом в `.p12`, API-ключ команды App Store Connect для `notarytool` и новый ключ EdDSA из `bin/generate_keys` Sparkle 2.10.0. Создайте отдельный ключ командой `bin/generate_keys --account holod` и экспортируйте его командой `bin/generate_keys --account holod -x <файл>`. Храните резервную копию ключа для последующих релизов. [Нотарификация Apple](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution/) · [Ключи Sparkle](https://sparkle-project.org/documentation/)
3. Добавьте защищённые переменные для окружения `production` в **Settings → CI/CD → Variables**. Секреты задайте как скрытые или маскируемые, где GitLab поддерживает это для их формата.

| Переменная | Тип | Значение |
| --- | --- | --- |
| `HOLOD_SIGN_IDENTITY` | Variable | Имя или SHA-1 сертификата Developer ID Application |
| `HOLOD_SIGN_P12_BASE64` | File | `.p12` в Base64, например вывод `base64 -i DeveloperID.p12` |
| `HOLOD_SIGN_P12_PASSWORD` | Variable | Пароль экспорта `.p12` |
| `HOLOD_NOTARY_KEY` | File | Содержимое файла API-ключа `.p8` |
| `HOLOD_NOTARY_KEY_ID` | Variable | Key ID из App Store Connect |
| `HOLOD_NOTARY_ISSUER_ID` | Variable | Issuer ID из App Store Connect |
| `HOLOD_SPARKLE_PRIVATE_KEY` | File | Закрытый ключ, экспортированный `generate_keys -x` |

Поднимите версию в `Cargo.toml` и `Cargo.lock`, затем отправьте защищённый тег с таким же номером, например `v0.1.5`. Задание `publish_macos` подпишет приложение и DMG, отправит DMG на нотарификацию, прикрепит билет Apple и опубликует последнюю версию с подписанным `appcast.xml` на GitLab Pages. После первого выпуска откройте Pages без входа и скачайте DMG. Для сквозной проверки установите его в «Программы», опубликуйте следующий релиз и обновитесь через **Check for Updates…**.

## Разрешение macOS

Для запуска из терминала разрешите доступ приложению терминала в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ» и полностью перезапустите терминал. Если macOS показывает в списке сам бинарник, добавьте `target/release/holod`. Разрешение нужно для чтения списка окон, переключения между ними и распознавания двойных нажатий. [Инструкция Apple](https://support.apple.com/guide/mac-help/mh43185/mac)

## CLI

```sh
./target/release/holod list
./target/release/holod focus '<id из первого столбца>'
```

`list` выводит три столбца через табуляцию: ID, приложение и заголовок. Используйте свежий ID. Он может измениться при переименовании, перемещении или изменении размера окна либо при перезапуске приложения или пересборке бинарника. Если несколько окон одного приложения имеют одинаковые доступные метаданные, список показывает отдельные ID с порядковыми номерами, а `focus` сообщает о неоднозначности. Переместите одно из окон и обновите список.

В список попадают обычные окна и диалоги, которые пользовательские приложения публикуют в Accessibility. Системные окна, служебные панели и приложения, не ответившие в пределах тайм-аута, пропускаются. Для диагностики можно запустить CLI с `RUST_LOG=debug`.

## Панель поиска

```sh
./target/release/holod gui
```

Панель использует Liquid Glass и требует macOS 26 или новее. Запуск без аргументов также включает поиск. Процесс работает без значка в Dock. По умолчанию панель открывает двойное быстрое нажатие и отпускание `Option`. Подходит левая или правая клавиша. Повторное нажатие сочетания скрывает панель.

Чтобы переназначить сочетание, выберите **Change Shortcut…** в меню снежинки, нажмите новые клавиши и выберите **Save Shortcut**. Кнопка **Use Double Option** возвращает двойное нажатие `Option`. Действующее сочетание сохраняется между запусками.

Для двойного нажатия подходят `Command`, `Option`, `Control`, `Shift` и обычные клавиши. Обычная клавиша продолжает действовать и в активном приложении. В окне настройки `Esc`, `Return` и `Tab` используются для управления диалогом.

При открытии выделено предыдущее окно. Недавно посещённые окна идут выше, а текущее окно находится в конце. Holod запоминает переключения с момента запуска, в том числе между окнами одного приложения. Строки компактнее, поэтому одновременно видно около десяти результатов.

Введите часть заголовка или названия приложения. Результаты сохраняют порядок по недавнему использованию. Стрелки `↑` и `↓` меняют выбор, `Enter` или двойной щелчок переключает на окно, `Esc` скрывает панель. Успешное переключение закрывает панель. Для завершения процесса нажмите `Ctrl+C` в терминале, из которого его запустили.

Поиск понимает запросы, набранные в английской раскладке вместо русской и наоборот. Например, `мы-сщву` и `мы-сжву` найдут VS Code. Если точных совпадений нет, поиск допускает одну неверную клавишу после смены раскладки в запросах из пяти или более букв.

Нажмите `⌘W` в панели, чтобы закрыть выделенное окно. Панель остаётся открытой и выделяет соседний результат. Если приложение запрашивает подтверждение, завершите закрытие в его диалоге.

## Spaces

При переключении macOS может перейти в Space, где уже открыто окно приложения. Включите параметр «При переключении на приложение переключаться на пространство с открытыми окнами этого приложения» в «Системные настройки → Рабочий стол и Dock → Mission Control». Через публичные API нельзя адресовать произвольный Space по ID. Если macOS не переводит фокус на выбранное окно, перейдите в нужный Space и повторите запрос. [Справка Apple о Spaces](https://support.apple.com/guide/mac-help/work-in-multiple-spaces-mh14112/mac)

## Ручная проверка

1. Откройте два окна VS Code с разными заголовками и убедитесь, что `list` показывает отдельный ID для каждого.
2. По очереди вызовите `focus` для обоих окон. Повторите со свёрнутым окном, окном другого приложения и окном на другом обычном Space.
3. Закройте окно и повторите `focus` со старым ID. Проверьте сообщение об ошибке и ненулевой код завершения.
4. Запустите `list` из процесса без доступа к Accessibility и проверьте подсказку о разрешении.
5. Запустите `gui` и дважды нажмите `Option` в другом приложении. Убедитесь, что поле поиска сразу принимает ввод, стрелки меняют выделение, `Enter` переключает на выделенное окно, а `Esc` закрывает панель. Проверьте, что удержание `Option` и сочетание `Option+←` оставляют панель закрытой.
6. После запуска Holod вручную переключитесь между двумя окнами одного приложения и окном другого приложения. Откройте панель. Проверьте, что первым выделено предыдущее окно, а фильтрация сохраняет порядок. Нажмите `Enter`, затем снова вызовите панель и проверьте, что первым стало окно, из которого вы переключились.
7. Откройте панель, введите часть названия двух тестовых окон и выделите одно из них. Нажмите `⌘W` и проверьте, что закрылось только выделенное окно, а запрос и панель сохранились. Повторите с окном, которому требуется подтверждение сохранения.
8. Из одного окна VS Code откройте Holod и выберите второе окно VS Code. Проверьте, что панель скрылась и ввод сразу поступает во второе окно. Повторите переход в обратную сторону и затем в окно другого приложения.
9. На первом запуске после выдачи «Универсального доступа» выберите **Skip** и проверьте двойное нажатие `Option`. Перезапустите Holod и убедитесь, что диалог больше не появляется.
10. Через **Change Shortcut…** нажмите `⌃⌥K`, проверьте отображение нажатых клавиш и сохраните сочетание. Проверьте открытие и скрытие панели этим сочетанием из другого приложения и после перезапуска. Откройте диалог ещё раз, нажмите другое сочетание и выберите **Cancel**. Проверьте, что `⌃⌥K` по-прежнему работает. Затем верните двойное нажатие `Option` через **Use Double Option**.
11. Запишите `⌘ → ⌘` через **Change Shortcut…** и проверьте, что два коротких нажатия показывают и скрывают панель. Одно нажатие, удержание `Command` и сочетание `⌘C` должны оставлять панель закрытой. Повторите проверку с двойным нажатием обычной клавиши.
12. Откройте VS Code и введите в панели поиска `vs-code`, `мы-сщву`, затем `мы-сжву`. Каждый запрос должен показать окна VS Code. Откройте окно с заголовком «Документ» и проверьте, что его можно найти запросом `ljrevtyn`.
13. Запустите установленный Holod с чистыми настройками и выберите **Not Now** в предложении об автозапуске. Перезапустите приложение и убедитесь, что предложение больше не появляется. Включите **Start at Login** через меню снежинки и проверьте наличие Holod в объектах входа macOS. Если требуется подтверждение, завершите его в «Системных настройках». Выйдите из учётной записи и войдите снова, чтобы проверить запуск.
14. Повторите проверку с чистыми настройками, выбрав **Start at Login** при первом запуске. Когда автозапуск включён, у пункта **Start at Login** должна появиться галочка. Удалите Holod из объектов входа в «Системных настройках» и проверьте, что пункт снова позволяет включить автозапуск.
