# holod

Нативный переключатель окон для macOS на Apple Silicon. Получает список окон через Accessibility API и позволяет выбрать отдельное окно приложения.

## Установка на macOS

1. Откройте `holod-<версия>-macos-arm64.dmg` и перетащите **holod** в **Программы (Applications)**.
2. Откройте holod из «Программ». При первом запуске нажмите **Open System Settings**. В «Конфиденциальность и безопасность → Универсальный доступ» включите holod. Если его нет в списке, нажмите «+» и выберите `/Applications/holod.app`.
3. Снова откройте holod. В строке меню появится снежинка с буквой **H**. Нажмите её и выберите **Search Windows** или дважды быстро нажмите и отпустите `Option`. Завершить приложение можно через **Quit holod** в меню снежинки или `⌘Q` в панели поиска.

Для установленного приложения нужна macOS 26 или новее и Apple Silicon.

## Обновление

Выберите **Quit holod** в меню снежинки, откройте новый DMG и перетащите holod в **Программы**. В Finder выберите **Заменить**, затем откройте holod из «Программ». Если macOS снова запрашивает разрешение после обновления локальной подписи, откройте «Универсальный доступ». При необходимости удалите старую запись holod, добавьте `/Applications/holod.app` и снова запустите приложение.

## Сборка

Нужны стабильный Rust с поддержкой edition 2024 и инструменты командной строки Xcode (`xcode-select --install`).

```sh
./packaging/macos/build.sh
```

Скрипт использует версию из `Cargo.toml` и создаёт `dist/holod.app` и `dist/holod-<версия>-macos-arm64.dmg`. Приложение подписывается локальной подписью ad hoc. Для распространения скачиваемой сборки Apple предусматривает подпись Developer ID и нотарификацию. [Документация Apple об упаковке приложений](https://developer.apple.com/documentation/xcode/packaging-mac-software-for-distribution)

Чтобы собрать бинарник для запуска из терминала, выполните:

```sh
cargo build --release --locked
```

## Разрешение macOS

Для запуска из терминала разрешите доступ приложению терминала в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ» и полностью перезапустите терминал. Если macOS показывает в списке сам бинарник, добавьте `target/release/holod`. Разрешение нужно для чтения списка окон, переключения между ними и распознавания двойного нажатия Option. [Инструкция Apple](https://support.apple.com/guide/mac-help/mh43185/mac)

## CLI

```sh
./target/release/holod list
./target/release/holod focus '<id из первого столбца>'
```

`list` выводит три столбца через табуляцию: ID, приложение и заголовок. Используйте свежий ID. Он может измениться при переименовании, перемещении или изменении размера окна либо при перезапуске приложения или пересборке бинарника. Если несколько окон одного приложения имеют одинаковые доступные метаданные, список показывает отдельные ID с порядковыми номерами, а `focus` сообщает о неоднозначности. Переместите одно из окон и обновите список.

В список попадают обычные окна и диалоги, которые пользовательские приложения публикуют в Accessibility. Системные окна, служебные панели и приложения, не ответившие в пределах тайм-аута, пропускаются. Для диагностики можно запустить CLI с `RUST_LOG=debug`.

## Панель поиска

```sh
./target/release/holod gui
```

Панель использует Liquid Glass и требует macOS 26 или новее. Запуск без аргументов также включает поиск. Процесс работает без значка в Dock. Для открытия панели дважды быстро нажмите и отпустите `Option`. Подходит левая или правая клавиша. Повторный жест скрывает панель.

При открытии выделено предыдущее окно. Недавно посещённые окна идут выше, а текущее окно находится в конце. holod запоминает переключения с момента запуска, в том числе между окнами одного приложения. Строки компактнее, поэтому одновременно видно около десяти результатов.

Введите часть заголовка или названия приложения. Результаты сохраняют порядок по недавнему использованию. Стрелки `↑` и `↓` меняют выбор, `Enter` или двойной щелчок переключает на окно, `Esc` скрывает панель. Успешное переключение закрывает панель. Для завершения процесса нажмите `Ctrl+C` в терминале, из которого его запустили.

Нажмите `⌘W` в панели, чтобы закрыть выделенное окно. Панель остаётся открытой и выделяет соседний результат. Если приложение запрашивает подтверждение, завершите закрытие в его диалоге.

## Spaces

При переключении macOS может перейти в Space, где уже открыто окно приложения. Включите параметр «При переключении на приложение переключаться на пространство с открытыми окнами этого приложения» в «Системные настройки → Рабочий стол и Dock → Mission Control». Через публичные API нельзя адресовать произвольный Space по ID. Если macOS не переводит фокус на выбранное окно, перейдите в нужный Space и повторите запрос. [Справка Apple о Spaces](https://support.apple.com/guide/mac-help/work-in-multiple-spaces-mh14112/mac)

## Ручная проверка

1. Откройте два окна VS Code с разными заголовками и убедитесь, что `list` показывает отдельный ID для каждого.
2. По очереди вызовите `focus` для обоих окон. Повторите со свёрнутым окном, окном другого приложения и окном на другом обычном Space.
3. Закройте окно и повторите `focus` со старым ID. Проверьте сообщение об ошибке и ненулевой код завершения.
4. Запустите `list` из процесса без доступа к Accessibility и проверьте подсказку о разрешении.
5. Запустите `gui` и дважды нажмите `Option` в другом приложении. Убедитесь, что поле поиска сразу принимает ввод, стрелки меняют выделение, `Enter` переключает на выделенное окно, а `Esc` закрывает панель. Проверьте, что удержание `Option` и сочетание `Option+←` оставляют панель закрытой.
6. После запуска holod вручную переключитесь между двумя окнами одного приложения и окном другого приложения. Откройте панель. Проверьте, что первым выделено предыдущее окно, а фильтрация сохраняет порядок. Нажмите `Enter`, затем снова вызовите панель и проверьте, что первым стало окно, из которого вы переключились.
7. Откройте панель, введите часть названия двух тестовых окон и выделите одно из них. Нажмите `⌘W` и проверьте, что закрылось только выделенное окно, а запрос и панель сохранились. Повторите с окном, которому требуется подтверждение сохранения.
