# Работа с проектом

- Используйте стабильный Rust, edition 2024. Целевая платформа — macOS на Apple Silicon.
- Получайте и активируйте окна через публичные API Accessibility и AppKit. Каждый блок `unsafe` должен объяснять предпосылки вызова и владение переданными объектами.
- AppKit-панель работает на главном потоке. Держите AX-вызовы и AX-объекты на рабочем потоке панели. Обновляйте список по запросу.
- Сохраняйте совместимость CLI `list` и `focus <id>`. Считайте AX-объекты недолговечными и проверяйте результат переключения.
- Перед отправкой изменений запускайте `cargo fmt --check`, `cargo check --locked`, `cargo clippy --locked --all-targets -- -D warnings` и `cargo test --locked`. При изменениях в AX или AppKit используйте ручные сценарии из README.
